# المرشد الحكومي الذكي — Gov AI Guide

## نظرة عامة

وحدة Odoo 17 Community تدمج مساعداً ذكياً يوجّه موظفي الحكومة المصرية في كل خطوة من خطوات العمل على نماذج ERP، مستشهداً بالقوانين واللوائح والقرارات الوزارية المصرية.

---

## المميزات الرئيسية

- **توجيه فوري**: عند النقر على أي حقل في أي نموذج Odoo، يظهر إرشاد حكومي مفصّل خلال ثانية واحدة
- **بث مباشر**: يظهر النص كلمة بكلمة (streaming) عبر Server-Sent Events
- **قاعدة معرفة مزدوجة**: تفهرس كود المصدر + الوثائق القانونية PDF
- **مراجع قانونية**: يستشهد بأرقام القوانين والمواد والقرارات الوزارية تلقائياً
- **تصميم حكومي**: شريط جانبي بألوان كحلي/ذهبي بخط Cairo بدعم RTL كامل
- **تدقيق كامل**: كل تلميح مُسجَّل مع المستخدم والحقل والقطع المستخدمة

## متطلبات التثبيت

### متطلبات Python

```bash
pip install anthropic numpy pymupdf sentence-transformers
```

### الإصدارات المدعومة

- Odoo 17 Community
- Python 3.10+
- anthropic >= 0.25.0
- numpy >= 1.24.0
- pymupdf >= 1.23.0
- sentence-transformers >= 2.2.0 (اختياري — يُحسّن جودة البحث)

## خطوات التثبيت

### 1. نسخ الوحدة

```bash
cp -r gov_ai_guide /path/to/odoo/addons/
```

### 2. تثبيت المتطلبات

```bash
pip install anthropic numpy pymupdf sentence-transformers
```

### 3. تثبيت الوحدة في Odoo

- افتح: **الإعدادات ← التطبيقات ← تحديث قائمة التطبيقات**
- ابحث عن "المرشد الحكومي" وانقر **تثبيت**

### 4. تعيين مفتاح Anthropic API

- افتح: **الإعدادات ← المعلمات التقنية**
- ابحث عن `gov_ai_guide.api_key`
- أدخل مفتاح API الخاص بك من [console.anthropic.com](https://console.anthropic.com)

### 5. (اختياري) رفع الوثائق القانونية

- افتح: **المرشد الحكومي ← قاعدة المعرفة ← الوثائق والقوانين**
- انقر **جديد** وارفع ملف PDF للقانون
- انقر **فهرسة الآن** لاستخراج المحتوى وبناء المتجه الدلالي

## طريقة العمل

```
المستخدم يركّز على حقل
        │
        ▼
field_tracker.js يكتشف الحقل + النموذج + القيمة
        │
        ▼
agent_connector.js يرسل طلباً عبر Server-Sent Events
        │
        ▼  (خادم Odoo)
/gov_ai/stream يستقبل الطلب ويستدعي AgentSession.process()
        │
        ├── البحث في قاعدة المعرفة (تشابه متجهي)
        ├── الرجوع لـ FIELD_HINT_CONTEXT (احتياطي)
        └── استدعاء Anthropic API (claude-sonnet-4-6) بالبث
                │
                ▼
        الرموز تصل للشريط الجانبي token بعد token
```

## هيكل المعلمات التقنية

| المفتاح | الوصف | القيمة الافتراضية |
|---------|-------|-------------------|
| `gov_ai_guide.api_key` | مفتاح Anthropic API | فارغ (إلزامي) |
| `gov_ai_guide.anthropic_model` | نموذج Claude المستخدم | `claude-sonnet-4-6` |
| `gov_ai_guide.max_tokens` | الحد الأقصى للرموز في الرد | `1024` |
| `gov_ai_guide.cache_size` | حجم الذاكرة المؤقتة | `50` |

## الأمان

- كل طلب WebSocket يُتحقق من `session_token` في قاعدة البيانات
- المستخدمون يرون فقط `agent_log` الخاص بهم
- وثائق `addon_source` قراءة فقط في الواجهة
- جميع المستخدمين يحصلون على التلميحات — المسؤول فقط يدير قاعدة المعرفة
