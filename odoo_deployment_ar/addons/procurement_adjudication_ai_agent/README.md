# وكيل تحليل العروض في البت الفني والمالي

## الهدف
تحليل العروض الفنية والمالية عند فتح المظاريف، وتجهيز مسودات عربية رسمية لمحاضر اللجنة والمقارنة المالية.

## نقاط التشغيل
- عند `action_open_technical`: تنفيذ التحليل الفني.
- عند `action_open_financial`: تنفيذ التحليل المالي.

## المخرجات
- نسبة مطابقة فنية لكل مورد.
- نقاط قوة وضعف لكل عرض.
- ترتيب مالي للموردين المستوفين فنياً.
- نسبة الانحراف عن القيمة التقديرية.
- تحذير إذا كان العرض أقل من القيمة التقديرية بأكثر من 15%.
- مسودة محضر البت الفني.
- مسودة المقارنة المالية.
- مسودة إخطار الترسية.

## ملاحظات
- التحليل الحالي On-Prem وقاعدي ولا يرسل بيانات للخارج.
- يمكن لاحقاً ربط دوال التحليل بـ Local LLM/OCR داخلي.
- نتائج الوكيل استرشادية ولا تغني عن قرار اللجنة المختصة.
