# وكيل فحص اكتمال الإضبارة قبل الصرف

## الهدف
منع اعتماد دفتر 55 إذا كانت الإضبارة المرتبطة غير مكتملة أو إذا أظهر الفحص الذكي وجود عدم تطابق في محتوى المرفقات.

## طريقة العمل
- يرث الموديول من `port_said.daftar55`.
- يتم تنفيذ الفحص قبل `super().action_approve()`.
- إذا كانت `dossier_id.is_complete = False` يتم منع الاعتماد فوراً.
- يتم عرض `missing_attachments` للمستخدم.
- يتم إنشاء سجل في `port_said.dossier.audit.log` لكل محاولة.
- الفحص الذكي اختياري من الإعدادات.

## ملاحظات مهمة
- نقص المرفقات يمنع الصرف دائماً.
- الفحص الذكي لا يرسل أي بيانات لخدمة خارجية.
- قراءة ملفات PDF تحتاج إلى وجود مكتبة `pdfminer.six` داخل كونتينر Odoo.
- ملفات PDF المصورة أو الصور تحتاج إلى OCR داخلي لاحقاً.
- يمكن ربط `_agent_verify_dossier_attachments` لاحقاً بـ Local LLM/OCR داخلي.
