# وكيل أتمتة الارتباطات من الطلب للتجنيب

## الهدف
تقليل الخطوات اليدوية بعد اعتماد طلبات الشراء/الاحتياج، بحيث يتم اعتماد وتجنيب الارتباطات الصغيرة منخفضة المخاطر تلقائياً.

## طريقة العمل
- يرث من `port_said.requisition` وهو اسم موديل الطلب الحقيقي داخل مشروعك.
- يستدعي `super().action_approve()` أولاً حتى يترك الكود الحالي ينشئ الارتباط.
- يبحث عن `commitment_id` أو أي ارتباط مرتبط بالطلب.
- إذا كان إجمالي الطلب أقل من أو يساوي حد الأتمتة، ولا توجد جزاءات، والمخاطر منخفضة، يقوم بتنفيذ:
  - `commitment.action_approve()`
  - `commitment.action_reserve()`
- إذا لم تتحقق الشروط، يسجل القرار ويرسل Activity للمراجع المختص.

## الإعدادات
من إعدادات Odoo:
- تفعيل أتمتة الارتباطات الصغيرة.
- حد الأتمتة التلقائية.
- اشتراط كفاية الرصيد المتاح.
- منع الأتمتة عند وجود جزاءات للمورد.
- المستخدم المسؤول عن المراجعة البشرية.

## ملاحظات
- تقييم المخاطر الحالي قاعدي On-Prem بدون إرسال بيانات للخارج.
- يمكن لاحقاً ربط `_agent_assess_requisition_risk` بـ Local LLM لتحليل مبرر الطلب والطلبات المشابهة.
