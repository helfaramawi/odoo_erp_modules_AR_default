# وحدة أدوات الاختبار والقبول (UAT)
## arabic_government_uat_demo
### محافظة بورسعيد — نظام إدارة الموارد الحكومية

---

## الوصف

وحدة Odoo 17 مخصصة لإعداد بيئة اختبار القبول (UAT) للجهات الحكومية العربية.
تتيح هذه الوحدة:

- **تنظيف آمن** لبيانات الحركات مع الحفاظ على البيانات الأساسية
- **توليد بيانات اختبار** عربية حكومية واقعية ومفصّلة
- **تغطية شاملة** لجميع مسارات العمل والسيناريوهات
- **مرجع دفعة موحد**: `UAT-AR-GOV-2026`

---

## التثبيت

### تثبيت لأول مرة

```bash
docker exec -it odoo17_app odoo -d odoo17_db -i arabic_government_uat_demo --stop-after-init
docker restart odoo17_app
```

### تحديث بعد تغيير الكود

```bash
docker exec -it odoo17_app odoo -d odoo17_db -u arabic_government_uat_demo --stop-after-init
docker restart odoo17_app
```

> **ملاحظة:** استبدل `odoo17_app` و `odoo17_db` بأسماء الحاوية وقاعدة البيانات الفعلية في بيئتك.

## التنظيف الجاف (Dry Run)

الخطوات:
1. افتح: **أدوات الاختبار والقبول → تنظيف بيانات الحركات**
2. تأكد من تفعيل: **تجربة جافة (بدون حذف فعلي)** ✓
3. اختر النطاق: `بيانات UAT-AR-GOV-2026 فقط`
4. اضغط **تشغيل التنظيف**
5. راجع النتائج في سجل التنظيف — لم يُحذف أي شيء

---

## التنظيف الفعلي (⚠ تحذير)

> **تحذير:** هذا الإجراء يحذف البيانات نهائياً. لا يمكن التراجع عنه.
> احتفظ بنسخة احتياطية من قاعدة البيانات قبل المتابعة.

الخطوات:
1. افتح: **أدوات الاختبار والقبول → تنظيف بيانات الحركات**
2. **أوقف** خيار: تجربة جافة
3. **فعّل** خيار: تأكيد التنظيف الفعلي
4. اختر النطاق المناسب:
   - `بيانات UAT-AR-GOV-2026 فقط` — الأكثر أماناً
   - `جميع بيانات الحركات` — للتنظيف الكامل (خطر)
5. اضغط **تشغيل التنظيف**

---

## توليد بيانات الاختبار

الخطوات:
1. افتح: **أدوات الاختبار والقبول → توليد بيانات اختبار حكومية**
2. تأكد أن مرجع الدفعة: `UAT-AR-GOV-2026`
3. فعّل الفئات المطلوبة (كلها مفعلة افتراضياً)
4. اضغط **توليد البيانات**
5. راجع ملخص النتائج في سجل التوليد

---

## إعادة التوليد بعد التنظيف

لإعادة بدء البيئة من الصفر:

1. **تنظيف أولاً:** شغّل التنظيف بنطاق `UAT-AR-GOV-2026 فقط`
2. **توليد ثانياً:** شغّل معالج التوليد مع تفعيل `إعادة تعيين بيانات UAT السابقة`

## تحذيرات الأمان

🚨 **لا تشغّل التنظيف الفعلي على قواعد البيانات الإنتاجية**

✅ **قبل أي تنظيف فعلي:**
- أخذ نسخة احتياطية كاملة
- التحقق من النطاق المحدد
- تأكيد الاختيار مرتين

✅ **البيانات المحفوظة دائماً (لن تُحذف أبداً):**
- الشركات والمستخدمون
- المجموعات والصلاحيات
- الموظفون والأقسام
- الموردون والعملاء (البيانات الأساسية)
- دليل الحسابات والضرائب
- الدفاتر اليومية والعملات
- الموازنات (إلا ما يحمل مرجع UAT)

## التوسيع والتخصيص

لإضافة وحدات جديدة للتوليد:
1. افتح `models/uat_data_generator.py`
2. أضف دالة `_generate_[module_name]` جديدة
3. أضف استدعاءها في دالة `generate_all`
4. أضف حقل الخيار في `wizard/uat_generate_wizard.py`

لإضافة نماذج للتنظيف:
1. افتح `wizard/uat_cleanup_wizard.py`
2. أضف النموذج في قائمة `CLEANUP_MODELS_ORDERED` بالترتيب الصحيح (الأبناء أولاً)
